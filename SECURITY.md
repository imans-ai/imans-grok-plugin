# Security

Report security issues privately to **security@imans.ai**. Include a description,
affected version and reproduction steps with credentials and business data
removed. Do not post vulnerabilities, OAuth tokens or signed links in public
issues. The canonical disclosure policy is https://imans.ai/security#report.

If a connection should no longer have access, revoke it in Imans and disconnect
the app in the host. Remove exposed credentials through the service that issued
them. This plugin stores no credentials in source files.
